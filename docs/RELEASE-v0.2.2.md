# CaptionForge v0.2.2

Corrige el selector del idioma de la interfaz: al cerrar el desplegable muestra únicamente Español o English, sin campos del objeto ni claves de traducción.

Validado al cambiar de idioma y recargar el catálogo. Conserva las funciones y correcciones de v0.2.1.

Windows x64 portable con .NET incluido. Extrae el ZIP completo antes de ejecutar CaptionForge.exe.
